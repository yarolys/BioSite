# BioSite — yarolys.ru

Персональный сайт-портфолио на Astro + Tailwind CSS + TypeScript.

## Возможности

- Светлая и тёмная тема с переключателем
- Плавный скролл и анимации появления при скролле
- Мягко падающие символы кода: фон привязан к странице, распределён по всей её высоте и замирает в неактивной вкладке
- Первый экран с текущей ролью, результатами и прямой ссылкой на Telegram
- Опыт работы с достижениями и навыки по направлениям
- Гном-пасхалка: открывается нажатием на домик, подсказка закрывается по Escape
- Три клика по гному запускают падение, слёзы и побег домой; фраза «Извини меня пожалуйста» запускает примирение и чай с тортиком. По гному также можно нажать Enter или пробел, когда он в фокусе. Сценка доступна на десктопе при разрешённых анимациях.
- Физика элементов на десктопе: тяните фото, отдельные слова, знаки и иконки мышью; бросок запускает возвращение на ножках через 5 секунд. Верните элемент к исходному месту, чтобы поставить его обратно. Escape отменяет игру, Alt позволяет выделять текст. Обычные клики по ссылкам сохраняются.
- Адаптивная вёрстка с бургер-меню
- Поддержка `prefers-reduced-motion`
- SEO: title, description, Open Graph
- Деплой через Docker или напрямую через Nginx

## Технологии

- [Astro](https://astro.build) — статический генератор
- [Tailwind CSS v4](https://tailwindcss.com) — утилитарные стили
- TypeScript
- Docker + Nginx

## Быстрый старт

```bash
npm install
npm run dev
```

Dev-сервер запустится на `http://localhost:4321`.

## Сборка

```bash
npm run build
npm run preview  # предпросмотр билда
```

## Docker

```bash
docker compose up -d
```

## Контент

Все данные находятся в `src/data/profile.ts`:

| Секция             | Описание              |
|--------------------|-----------------------|
| `profile`          | Имя, должность, соцсети |
| `heroSection`      | Описание и показатели первого экрана |
| `aboutSection`     | Текст «О себе» |
| `skillGroups`      | Навыки по направлениям |
| `experienceSection`| Опыт работы           |
| `educationSection` | Образование           |
| `hobbiesSection`   | Хобби                 |
| `seoData`          | SEO-метаданные        |
